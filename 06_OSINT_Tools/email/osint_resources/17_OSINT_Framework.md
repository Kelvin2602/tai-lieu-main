## 🎯 Chức năng

OSINT Framework là một framework tập trung vào việc thu thập thông tin từ các công cụ hoặc tài nguyên miễn phí. Mục đích là giúp mọi người tìm các tài nguyên OSINT miễn phí. Framework này được tổ chức dưới dạng web application với giao diện trực quan.

### Tính năng chính:
- **Web-based Interface:** Giao diện web dễ sử dụng
- **Free Resources:** Tập trung vào các tài nguyên miễn phí
- **Categorized:** Được phân loại rõ ràng
- **Search Functionality:** Có chức năng tìm kiếm
- **Legend System:** Hệ thống ký hiệu để phân biệt loại công cụ

### Legend (Ký hiệu):
- **(T)** - Tool phải được cài đặt và chạy locally
- **(D)** - Google Dork
- **(R)** - Yêu cầu đăng ký
- **(M)** - URL chứa search term và phải chỉnh sửa thủ công

## 🎯 Cách sử dụng

### Sử dụng Web Application:
1. Truy cập https://osintframework.com
2. Duyệt qua các danh mục
3. Click vào công cụ để truy cập
4. Sử dụng chức năng tìm kiếm nếu cần

### Chạy Local:
1. Clone repository: `git clone https://github.com/lockfale/OSINT-Framework.git`
2. Cài đặt dependencies (nếu cần)
3. Mở `public/index.html` trong trình duyệt
