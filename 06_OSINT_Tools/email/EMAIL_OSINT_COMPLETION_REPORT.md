## 🔧 CÁCH SỬ DỤNG:

### Holehe:
```bash
cd holehe
python setup.py install
holehe target@email.com
```

### h8mail:
```bash
cd h8mail
pip install -r requirements.txt
h8mail -t target@email.com
```

### Blackbird:
```bash
cd blackbird
pip install -r requirements.txt
python blackbird.py --email target@email.com
```

### Sherlock:
```bash
cd sherlock
pip install -r requirements.txt
python sherlock target@email.com
```

### Maigret:
```bash
cd maigret
pip install -r requirements.txt
python maigret.py username
```

### PhoneInfoga:
```bash
cd PhoneInfoga
pip install -r requirements.txt
python phoneinfoga.py -n +1234567890
```

### Gitrecon:
```bash
cd gitrecon
npm install
node gitrecon.js --email target@email.com
```
