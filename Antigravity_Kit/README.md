# Antigravity Skills Kit

Bộ công cụ tích hợp các kỹ năng AI nâng cao (UI/UX Pro, Product Manager, Architect...) cho Agent Antigravity.

## 🛠 Hướng dẫn Tích hợp (Sử dụng cho toàn bộ dự án sau này)

Để tích hợp bộ kỹ năng này vào bất kỳ dự án mới nào của bạn, hãy làm theo một trong hai cách sau:

### Cách 1: Sử dụng Script (Nhanh nhất)
Mở Terminal tại thư mục dự án mới và chạy lệnh:
```powershell
& "D:\tai-lieu-main\Antigravity_Kit\install_skills.ps1"
```

### Cách 2: Copy thủ công
Copy toàn bộ thư mục `D:\tai-lieu-main\Antigravity_Kit\Skills` vào thư mục `.agent/skills` trong dự án của bạn.

## 📚 Danh sách Kỹ năng (Skills)

### 🎨 UI/UX Design (ui-ux-pro-max)
- Tự động tạo Design System chuẩn (Màu sắc, Typography, Spacing).
- Phân tích yêu cầu và đề xuất giao diện theo từng ngành hàng (Spa, Fintech, E-commerce...).
- Hỗ trợ code Tailwind/React tối ưu.

### 🧠 Product & Architecture (TraeSkill)
- **01_ProductManager**: Viết PRD, User Stories, phân tích tính năng.
- **01_Architect**: Chọn Tech Stack, thiết kế API, cấu trúc Database.
- **02_Designer**: Hướng dẫn UX, luồng người dùng.

### 💻 Development Roles
- **03_ReactBestPractices**: Code React/Next.js chuẩn, tối ưu hiệu năng.
- **05_Backend**: Node.js, Python, Database optimization.
- **04_Tester**: Tự động hóa kiểm thử trình duyệt.
- ... và nhiều chuyên gia khác.
