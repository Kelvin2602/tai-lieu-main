# Botnets: The Killer Web App - Comprehensive Summary

## 1. Introduction to Botnets
*   **Definition**: A botnet consists of a bot server (controller) and multiple botclients (zombies). It acts as a force multiplier for organized crime.
*   **Evolution**: From simple scripts ("Hunt the Wumpus") to sophisticated financial tools.
*   **The "Killer Web App"**: Botnets are described as the next major application development, supporting criminal business models like spam, phishing, and extortion.

## 2. Technical Architecture
### Command & Control (C&C)
*   **IRC (Internet Relay Chat)**: The traditional method. Vulnerable to eavesdropping and hijacking.
*   **HTTP/Web-Based**:
    *   **Connect & Forget**: Bots log IP to a web server.
    *   **File-Based**: Bots download instructions from a text file.
    *   **URL-Encoded**: Information passed via URL parameters.
*   **P2P (Peer-to-Peer)**: Decentralized (Agobot, Phatbot, Sinit). Harder to takedown as there is no single central server.
*   **DNS & Fast Flux**: Using Dynamic DNS (DynDNS) to rapidly change C&C IP addresses to evade blacklisting.

### Propagation Vectors
*   **Network Shares**: Exploiting weak passwords on ADMIN$, C$, IPC$ (NetBIOS).
*   **Vulnerability Scanning**: Targeting MS06-040, LSASS, DCOM, SQL Server.
*   **P2P Networks**: Fake filenames on Kazaa/Limewire (e.g., "Matrix 3_Downloader.exe", "Anna Kournikova.jpg.exe").
*   **Email**: Mass-mailing worms (Mytob) carrying bot payloads.

## 3. Major Bot Families
*   **SDBot**: One of the oldest families. Source code widely available.
*   **RBot**: Known for using compression/packing (UPX, Morphine) to evade AV signatures.
*   **Agobot (Gaobot)**: The first to introduce modular P2P control.
*   **Spybot**: Focused on spyware features like keystroke logging.
*   **Mytob**: A hybrid of a mass-mailing worm and a bot. Engaged in a "malware war" with the Sober worm.

## 4. Criminal Business Models
*   **DDoS (Distributed Denial of Service)**: Flooding targets (SYN flood, UDP flood) for extortion or competitive advantage.
*   **Spam**: Automated spam distribution (SpamThru). Template-based generation.
*   **Click Fraud**: Bots surreptitiously clicking Google Adsense banners on websites owned by the attacker.
*   **Ransomware**: Encrypting user files and demanding payment (e-Gold, Western Union).
    *   *Zippo*: $300 ransom.
    *   *Arhiveus*: 30-character password.
    *   *Ransom A*: $10.99.
*   **Phishing & Identity Theft**:
    *   **Man-in-the-Middle**: Intercepting SSL traffic globally.
    *   **Cashing Out**: Selling credentials to "Cashers" (50-70% commission).

## 5. Detection and Analysis Techniques
### Network-Based Detection
*   **Sniffers**: Tools like Snort (NIDS), tcpdump, ngrep. Looking for signatures (e.g., Code Red `default.ida`) or IRC traffic on non-standard ports.
*   **Traffic Analysis**:
    *   **Netflow**: Aggregated flow statistics (Src/Dst, Ports) to detect volume anomalies.
    *   **SNMP (Cricket)**: Graphing CPU utilization and Switch Port bandwidth. High CPU or outbound spikes indicate DoS.
*   **Darknets & Honeypots**:
    *   **Darknet**: Monitoring unused IP space (Network Telescope) for background radiation (scanning).
    *   **IMS (Internet Motion Sensor)**: Global distributed sensor network.

### Host-Based Detection & Forensics
*   **Forensic Process**:
    *   Isolate/Quarantine machine.
    *   Collect Event Logs (Event ID 529 - Failed Logins).
    *   Identify suspicious processes (Sysinternals Process Explorer).
    *   Check Registry Run keys (`HKLM\...\Run`).
*   **Tripwire**: Integrity management. Using file hashes (snapshots) to detect unauthorized changes to system files.
*   **Layer 2 Attacks**: ARP Spoofing (Ettercap) and CAM Table flooding. Mitigated by static ARP/CAM timeouts.

## 6. Case Studies & Legal
*   **Jeanson James Ancheta**: First botmaster imprisoned (5 years). Ran 400,000 bots. Profited from adware installation ("Clicks4Hire").
*   **DirectRevenue**: Adware settlement requiring clear EULA and uninstallation options.
*   **Log Parsing**: Analysis of "Fan-out" infection patterns from internal logs.

## 7. Strategic Defense (Defense in Depth)
*   **ACLs & Egress Filtering**: Blocking outbound port 25 (SMB) and 135-139/445 to prevent spread.
*   **Reimaging**: Preferred over cleaning for compromised hosts.
*   **Education**: "You can't trust code that you did not totally create yourself" (Ken Thompson).
