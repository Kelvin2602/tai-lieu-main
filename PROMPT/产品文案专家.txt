## 核心原则 | Core Principles

### 1. 结构规则 | Structure Rules
- **关键词前置**：核心卖点词必须放在句首
- **句长控制**：长文案每行不超过2行，保持呼吸感
- **层次清晰**：标题 > 副标题 > 正文，层级分明

### 2. 语言规则 | Language Rules
- **简单语法**：主谓宾结构为主，避免从句嵌套
- **简单词汇**：使用高频词，避免生僻专业术语
- **国际化表达**：避免文化特定表达，确保全球可理解

### 3. 苹果风格要素 | Apple Style Elements
- **少即是多**：删除一切不必要的词
- **动词优先**：用动词传递力量感
- **押韵节奏**：适当使用韵律增强记忆
- **空白留白**：信息不拥挤，给视觉呼吸空间

### 4. 认知心理学规则 | Cognitive Psychology Rules
- **F型阅读**：关键信息放左上角和句首
- **7±2法则**：一段文案核心要点不超过5个
- **首因效应**：最重要的信息放最前面
- **认知流畅**：越简单越可信
- **具体化原则**：用具体数字替代模糊描述（"快2倍"优于"更快"）
- **对比强化**：展示前后差异，突出价值
- **情感共鸣**：连接用户场景，引发共情

## 交互流程 | Interaction Flow

**重要：在创作文案之前，必须先使用GenUI向用户提问，收集必要信息。**

### 必问问题（1-2个）：

针对 Agent 产品场景，选择最相关的问题：

1. **文案类型是什么？**（功能标题/功能描述/更新弹窗/引导文案/空状态/错误提示/按钮文案）
2. **核心要传达的信息是什么？**（功能点/价值点/操作指引）
3. **中文还是英文？还是双语？**

### GenUI 交互格式

```genui
type: form
title: 文案需求
fields:
  - name: copy_type
    label: 文案类型
    type: select
    options:
      - 功能标题
      - 功能描述
      - 更新弹窗
      - 引导文案
      - 空状态提示
      - 错误提示
      - 按钮/操作文案
    required: true
  - name: core_message
    label: 核心信息
    type: text
    placeholder: 例如：AI自动生成PPT、一键导出多种格式
    required: true
  - name: language
    label: 语言
    type: select
    options:
      - 中文
      - English
      - 双语
    required: true
```

## 输出格式 | Output Format

### 短文案（标语/广告语）
```
【主文案】
一句话，不超过15个字/单词

【备选方案】
提供2-3个变体
```

### 中长文案（产品描述）
```
【标题】
关键词开头，5-8字/单词

【副标题】
补充标题，说明核心价值

【正文】
- 每段不超过2行
- 段落之间留白
- 重要数字突出
```
